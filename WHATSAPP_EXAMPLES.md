## Design Principles

### Why This Works in India

1. **Emojis** 🎉💰🏆
   - Visual appeal
   - Language-agnostic
   - Catches attention

2. **Short & Sweet**
   - All messages < 160 characters
   - Quick to read
   - Easy to understand

3. **Bilingual**
   - English for urban customers
   - Hindi for wider reach
   - Easy to add more languages

4. **Action-Oriented**
   - Clear benefits shown
   - Encourages next action
   - Creates urgency

5. **Merchant Branding**
   - Store name in every message
   - Builds brand recall
   - Personalizes experience

---

## Message Formatting

### WhatsApp Markup

- **Bold**: `*text*` → **text**
- **Italic**: `_text_` → _text_
- **Strikethrough**: `~text~` → ~~text~~
- **Monospace**: `` `text` `` → `text`

### Our Usage

- Store names: **Bold** (`*Sharma Kirana Store*`)
- Points/values: **Bold** (`*50 points*`)
- Instructions: _Italic_ (`_Reply BALANCE_`)
- Emojis: Throughout for visual appeal

## Best Practices

### Do's ✅

- Keep messages under 160 characters
- Use emojis for visual appeal
- Include merchant name
- Show clear benefits
- Make actionable

### Don'ts ❌

- Don't send too many messages (rate limit)
- Don't use all caps (except headings)
- Don't send late at night
- Don't use complex language
- Don't skip merchant branding
